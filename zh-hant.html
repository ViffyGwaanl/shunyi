02隱私

沒有帳號，沒有伺服器，沒有統計

開發者收不到你翻譯的任何內容，也收不到任何關於你的資料。

  • 在你的 Mac 上完成

    離線翻譯和截圖文字辨識，用的都是 macOS 內建的功能，在本機完成，不經過網路。

  • 只去你指定的地方

    只有你自己填了 AI API，要翻譯的文字才會從你的 Mac 直接傳到那個 API，不經過我們。

  • 紀錄留在本機

    設定和最近 200 筆翻譯紀錄只存在 App 自己的沙盒裡，隨時可以清除，刪掉 App 就一起清掉。

03第一次使用

裝好以後，看一眼這四項

第一次打開會跳出設定視窗，概覽頁列著四項。前兩項弄好就能用了。

  1. 輔助使用權限 必要

    慢頁翻譯靠它在你按下快速鍵的那一刻模擬一次複製，拿到選取的文字；你選擇取代時再模擬一次貼上。它不會記錄你的鍵盤輸入。

  2. 離線翻譯語言包 建議

    下載一次，之後沒有網路也能翻譯。母語在「一般 → 語言」裡選。

  3. 螢幕錄製 可選

    打開以後，框選翻譯時畫面會先凍住，方便截影片字幕。

  4. AI 精譯 可選

    在設定的「AI 精譯」裡填你自己的 API 位址和 API Key（相容 OpenAI）。Chat Completions 和 Responses 兩種 API 類型都支援，模型思考可以開，也可以關。

04常見問題

卡住的時候，先看這裡

按了沒反應

多半是輔助使用權限沒開。打開「系統設定 → 隱私權與安全性 → 輔助使用」，把慢頁翻譯打開。如果已經開著，關掉再開一次。

支援哪些語言

20 種，可以互譯：繁體中文、简体中文、English、日本語、한국어、Français、Deutsch、Español、Italiano、Português、Русский、العربية、ไทย、Tiếng Việt、Bahasa Indonesia、Türkçe、Polski、Nederlands、Українська、हिन्दी。介面有繁體中文、简体中文和 English。

只出離線譯文，沒有 AI 譯文

AI 精譯要你自己填 API 位址和 Key。填好以後點「測試翻譯」，看連不連得上。如果提示不支援 Responses，把 API 類型換回 Chat Completions。

問 AI 的時候，問題沒有自動送出

有的網站不支援在網址裡預先填好問題，這時慢頁翻譯會把問題放進剪貼簿，點一下輸入框，按 ⌘V 就行。第一次用某個網站，要先在瀏覽器裡登入一次。

想用遙控器

Siri Remote 的按鍵要搭配第三方工具 HyperVibe 使用。在設定的「快速鍵與遙控器」頁點「授權 HyperVibe 設定檔案夾⋯」，選取 ~/.config/siriremote，之後就能在下拉選單裡替遙控器按鍵指定動作。

怎麼移除

結束慢頁翻譯，把它從「應用程式」拖到垃圾桶。設定和翻譯紀錄都在它自己的沙盒容器裡，會一起清掉。

遇到別的問題，或者有想法，請到 GitHub Issues 留言，寫上 macOS 版本、慢頁翻譯版本和操作步驟。
