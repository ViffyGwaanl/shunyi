# 慢页翻译

Mac 菜单栏里的随手翻译：选中一句，按一下，就懂了。

这个仓库放慢页翻译的帮助页和隐私政策（GitHub Pages）。问题和建议请提 Issue。

## 改这个站

- 下载按钮的网址在 `site.js` 最上面的 `LINKS` 里，留空时按钮显示「即将上架」。
- 网址后面加 `?demo=idle|selected|pressed|local|ai` 可以把首屏演示停在某一步，截图时用。
- 没有统计，没有外部字体和脚本。简体页 `index.html`，繁體页 `zh-hant.html`，英文页 `en.html`，隐私政策 `privacy.html`（含繁體和英文摘要）。三个首页结构相同，改一处记得另外两页也改。
